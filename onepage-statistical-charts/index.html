01
复式统计表 + 复式条形图认知 DOUBLE BAR · INTRO

复式统计表 4 要素:标题 + 日期 + 线条(横/竖) + 表格(行列表头)。它把 2 个或多个统计内容的数据合并在一张表上,清晰明了地反映数据情况。

复式条形统计图:每组数据中有 2 个或 2 个以上的数据,用几种不同颜色(或阴影/填充)的直条表示。

📐 读图 3 步:① 看标题(知道统计什么) → ② 看图例(知道哪种颜色/样式代表哪一组) → ③ 看数据(读直条高度/长度 + 横轴标签)。
✅ 复式条形图优点:能清楚表示各种数量的多少,可以更直观、形象地比较 2 种或多种数量之间的关系。

纵向 vs 横向 复式条形图 怎么选?

类别数数据大小选用理由
较多(>4 类)较小(几十~几百)纵向(直条往上长)横轴放得下所有类别名
较少(2~3 类)较大(几千~几万)横向(直条往右长)长的数据横向更易画、读

02
🎨 复式条形图 — 画图 5 步(重点) DRAW STEPS · ⭐ MUST

画图要素清单:标题 + 横轴标签 + 纵轴标签 + 刻度 + 0 + 直条 + 数据标签 + 图例 + 日期(9 件齐全)。

✏️ 必背口诀 · 画图 5 步:
① 备工具(尺子、铅笔、橡皮) → ② 写单位、画坐标轴(横/纵 + 0) → ③ 定单位长度(0~200 太大就画波浪线/闪电线断轴) → ④ 不同组用不同颜色/阴影/填充区分 → ⑤ 写标题 + 图例 + 日期。

画图 5 步详解(必考实操题):

步骤具体操作常见错误
① 备工具 尺子、铅笔、橡皮、彩笔(或阴影笔) 徒手画导致直条不直
② 写单位,画坐标轴 先画横轴(类别),再画纵轴(数量);标出"0"和两轴名称(如"体重(kg)"、"人数") 忘标"0"或忘写两轴名称
③ 定单位长度 1 cm 代表多少?(如 1 cm = 10 人);数据大时(如 0~1000),用波浪线 / 闪电线断轴 数据大但不断轴,图画不下
④ 区分两组数据 不同组用不同颜色;无彩笔时用阴影(斜线)和实心填充区分;直条宽窄必须相同 两组颜色相同无法区分;直条宽窄不一
⑤ 写标题 + 图例 + 日期 图上方写标题(说明统计什么);图下方写图例(颜色对应哪组);最后写制图日期;每个直条上要标数据 忘写标题;忘写图例;忘标数据

典型例题 3 道(⭐ 实操必考):

题号题目规范做法
① 画图题 统计 5(1) 班男女生最喜欢的运动(篮球/足球/乒乓/羽毛球),请画复式条形统计图 横轴=4 种运动,纵轴=人数,每组 2 根直条(蓝=男 粉=女),直条上标人数
② 改错题 小明的图忘写"0"、直条宽窄不一、没图例、两组颜色一样 ① 补"0" ② 重画等宽直条 ③ 加图例 ④ 两组换不同颜色或一阴影一实心
③ 选形式 统计某城市 2015~2020 出生人口(5 年,数据上千),画纵向还是横向? 横向(类别少=5 年,数据大=上千,横向长直条更易画)
03
📈 复式折线统计图(重点) DOUBLE LINE · ⭐ MUST

复式折线统计图:每组数据中有 2 个或 2 个以上的数据,用几种不同颜色(或样式)的折线 + 数据点表示。

画法:用一个单位长度表示一定数量,根据数量多少描出各点(每个点标上数据),然后把各点用线段顺次连接。

✅ 复式折线图优点:不仅能表示数量的多少,更能清楚地表示出数量增减变化的情况(=趋势),比较 2 条折线的上升/下降/波动。

📐 复式条形 vs 复式折线 区别(⭐ 必考选图):

维度复式条形图复式折线图
形状直条(长方形)折线(线段 + 数据点)
主要反映数量的多少数量的增减变化(趋势)
横轴时间(年份/月份),间隔按实际时间比例
适合场景不同类别比较同一对象随时间变化
判断"趋势"不方便方便(看线升/降/平)
📘 选图口诀:
"看多少 → 条形;看变化 → 折线;看占比 → 扇形"。
例:"某市 5 年气温变化" → 折线(看变化);"两班人数对比" → 条形(看多少);"全班同学血型占比" → 扇形(看占比)。
图 2: 复式折线(实线=甲 虚线=乙,看增减变化)

题号题目答案
① 识图 图 2 中,甲地哪个月气温最高?乙地呢? 甲地 7 月(30°);乙地 7 月(25°)

04
🎯 三种统计图选图决策 + 扇形简提 WHICH CHART · DECISION

三种统计图对比总表(⭐ 必考选图题):

统计图用 什么 画主要 优点典型 场景
条形统计图 直条(长方形) 很容易看出各种数量的多少 不同类别数量对比(人数/产量)
折线统计图 线段(折线 + 数据点) 不仅看多少,更能看增减变化 同一对象随时间变化(气温/成绩)
扇形统计图 整个圆 + 扇形 很清楚看各部分 占总数 的 % 总体中各部分占比(血型/支出)
🎯 选图决策口诀:
看"多少" → 条形;看"增减" → 折线;看"占 %" → 扇形。
关键词识别:"谁多谁少"=条形;"上升/下降/趋势"=折线;"占总数的百分之几"=扇形。

扇形图简提:

定义:用整个圆的面积表示总数(100%),用扇形面积表示各部分所占总数的百分数。
圆周角 = 360°,各扇形圆心角 = 该部分百分比 × 360°(例:30% × 360° = 108°)。
本单元不展开画法,六年级"扇形统计图"单元会系统学习。

红叉误区 PITFALLS · 4 COMMON MISTAKES
✗
画复式条形图两组数据都用同一种颜色(或一种填充),没图例
👉 两组数据必须用不同颜色或阴影/实心区分,并在图下方写图例(颜色对应哪组)。否则图白画了,无法读出信息。
✗
画条形图时直条宽窄不一,有的胖有的瘦
👉 直条宽窄必须相同(只看长度比多少);并且每组内 2 根直条之间也要留同样的间隙。
✗
画图时数据范围 0~1000 没断轴,直条顶到天花板
👉 数据太大画不下时,在纵轴"0 上方"画波浪线 / 闪电线断轴,标上断开的数字(如 100),再继续画。
✗
"某地 5 年气温变化"画成了条形图,看不出趋势
👉 横轴是时间 + 要看变化趋势 → 选折线图。条形图只反映每年多少,看不出升/降。

✏️ 一句话总结

本单元必考 2 大图 + 1 决策: 复式条形(直条,看多少,5 步画法) + 复式折线(线段,看变化趋势) + 选图口诀("看多少→条形/看变化→折线/看占比→扇形")。
画图 9 件齐全:标题 + 横轴 + 纵轴 + 刻度 + 0 + 直条/线段 + 数据 + 图例 + 日期。 忘图例 / 直条宽窄不一 / 数据大不断轴 = 直接扣分。
