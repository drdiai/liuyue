第二单元《圆》结构化知识网络

Knowledge Structure
体系框架 三大主线串联圆的核心考点

主线 1：圆的特征与要素 ➔ 圆心 O（决定位置）、半径 r（决定大小）、直径 d ($d=2r$)、“一中同长”。
主线 2：对称与作图 ➔ 轴对称图形、无数条对称轴（直径所在直线）、折纸找圆心、弦的中垂线求圆心。
主线 3：周长与面积 ➔ 化曲为直与圆周率 $\pi$ $\to$ 周长 $C=2\pi r$ $\to$ 剪拼转化推导面积 $S=\pi r^2$ $\to$ 圆环与组合图形阴影。

02

核心公式全集与双向换算汇总表

Formula Summary Table
计算项目 正向计算公式 逆向求半径 r 或直径 d 公式
直径与半径 $d = 2r$ $r = \frac{d}{2}$
圆的周长 C $C = \pi d = 2\pi r$ $d = \frac{C}{\pi}$， $r = \frac{C}{2\pi}$
圆的面积 S $S = \pi r^2 = \pi \left(\frac{d}{2}\right)^2$ $r^2 = \frac{S}{\pi} \implies r = \sqrt{\frac{S}{\pi}}$
圆环面积 S $S_{\text{环}} = \pi (R^2 - r^2)$ $R^2 - r^2 = \frac{S_{\text{环}}}{\pi}$
半圆周长 C $C_{\text{半圆}} = \pi r + 2r \approx 5.14 r$ $r = \frac{C_{\text{半圆}}}{\pi + 2} \approx \frac{C_{\text{半圆}}}{5.14}$

三大高频必考模型秒杀公式

3 High-Frequency Models
模型 1 外方内圆 (四周阴影)

公式：
阴影面积 $= (4 - \pi) r^2$
$\approx 0.86 r^2$

模型 2 外圆内方 (四弓形阴影)

公式：
阴影面积 $= (\pi - 2) r^2$
$\approx 1.14 r^2$

模型 3 倍数变化规律

半径/直径扩大 k 倍：
• 周长扩大 k 倍
• 面积扩大 $k^2$ 倍

期末易错陷阱大盘点

Pitfalls Summary
🚨 概念坑：直径与对称轴

❌ 错误：“圆的直径是对称轴。”
✔ 正确：对称轴是直线，正确说法为“直径所在的直线是圆的对称轴”。

🚨 计算坑：半圆周长漏加直径

❌ 错误：半圆周长 $= \pi r$。
✔ 正确：半圆封闭图形包括弧长与底边直径：$C_{\text{半圆}} = \pi r + 2r$！

🚨 运算坑：r² 与 r × 2 混淆

❌ 错误：把 $r^2$ 算成 $r \times 2$（如 $4^2 = 8$）。
✔ 正确：$r^2 = r \times r$（$4^2 = 16$）。

🚨 公式坑：圆环面积误用 π(R - r)²

❌ 错误：$S_{\text{环}} = \pi (R - r)^2$。
✔ 正确：必须先算平方差再乘 $\pi$：$S_{\text{环}} = \pi (R^2 - r^2)$！
