YOLO
You Only Look Once
端到端实时目标检测模型 · 一页通

核心思想

只"看"一次，一次性完成所有检测。不滑窗、不提案区域——直接把整张图送入一个卷积神经网络，同时输出检测框坐标 + 物体类别 + 置信度。

传统方法（R-CNN系列）两步走：先生成候选区域，再分类回归。YOLO 合二为一，因此推理速度极快，适合实时视频流、自动驾驶、监控等场景。

工作原理（三步走）

1
网格划分：输入图像被划分为 S×S 个网格。每个格子负责预测落在其内的目标。
2
边界框预测：每个格子输出 B 个边界框（x,y,w,h） + 置信度 + C 个类别概率，一次性完成。
3
NMS后处理：用非极大值抑制筛除重叠框，保留最精确的检测结果。
输入 448×448×3  →  CNN Backbone  →  S×S×(5B+C)  →  NMS  →  检测结果

发展历程

YOLOv1 (2016)
Joseph Redmon 提出，首个单阶段检测器。448×448 输入，7×7 网格。
YOLOv2 / v3 (2017–18)
引入锚框、多尺度训练、Darknet-53 骨干网络、FPN 多尺度预测。
YOLOv4 / v5 (2020)
Cross-Stage-Partial 连接、Mish 激活、SPP、PANet；v5 转向 PyTorch。
YOLOv6 / v7 (2022)
重参数化、E-ELAN、辅助头训练，工业级部署优化。
YOLOv8 / v10 / v11 (2023–25)
Ultralytics 主导。Anchor-Free、实例分割+姿态估计+旋转框，多任务统一框架。

YOLO 标注格式

每张图片对应一个 .txt 标注文件，每行一个目标：

class  x_center y_center width height
0   0.523 0.387 0.156 0.214
1   0.218 0.664 0.094 0.183

所有坐标均为归一化值（0–1），相对整图宽高。

优势 & 局限

✅ 核心优势

  • 实时推理，单次前向传播完成全部检测
  • 端到端训练，无需复杂的流水线
  • 全局感受野，背景误检率低
  • 丰富的预训练模型和生态
  • 多任务：检测+分割+姿态+分类

⚠️ 已知局限

  • 小目标 / 密集重叠场景精度不如两阶段
  • 每格固定 B 个框，拥挤场景漏检
  • 定位精度受网格粒度限制
  • 早期版本对非常规比例物体敏感
